Chuẩn game GameHub

Tài liệu cho nhà phát triển: cách đóng gói game HTML5 để chạy trên GameHub, lấy dữ liệu người chơi, lưu điểm/thành tựu và được duyệt.

Quy trình

  1. Làm game HTML5 (Canvas/WebGL/Phaser/Three.js… tùy bạn) — mọi file đều nằm trong gói, không tải CDN.
  2. Thêm gamehub.json (khai báo thông tin, thể loại, bảng điểm, thành tựu) và nhúng gamehub-sdk.js.
  3. Chạy thử cục bộ: npm run validate -- ./thu-muc-game. Mở index.html trực tiếp cũng được — SDK tự chuyển sang chế độ mock.
  4. Nén thành .zip và gửi ở trang Đăng game. Máy chủ kiểm tra tự động.
  5. Quản trị viên xem thử và duyệt. Bị từ chối sẽ có ghi chú lý do để bạn sửa và gửi lại. Cập nhật game: tăng version rồi gửi lại.

1. Cấu trúc gói .zip

my-game.zip
├── gamehub.json        ← bắt buộc, ở thư mục gốc
├── index.html          ← entry (đổi được bằng "entry")
├── gamehub-sdk.js      ← SDK (tải ở /sdk/gamehub-sdk.js)
├── thumb.png           ← ảnh đại diện 640×360, ≤ 512KB
├── game.js, style.css, assets/...

Nếu bạn nén cả thư mục, hệ thống tự bỏ thư mục gốc. Giới hạn: zip ≤ 30MB, giải nén ≤ 80MB, ≤ 600 file, mỗi file ≤ 25MB. Định dạng cho phép: html js css json png jpg gif webp svg ico mp3 ogg wav m4a woff woff2 ttf otf glb gltf bin wasm txt md xml atlas.

3. GameHub SDK

<script src="gamehub-sdk.js"></script>
<script>
  const info = await GameHub.init();           // { player, game, settings, preview, mode }
  // player = { id, username, displayName, avatar, guest }  (guest = true nếu chưa đăng nhập)

  const saved = await GameHub.load();          // dữ liệu đã lưu (hoặc null)
  /* ... tải xong tài nguyên ... */
  GameHub.ready();                             // tắt màn hình loading của portal

  GameHub.gameStart();                         // bắt đầu lượt chơi (thống kê)
  // ... khi thua:
  const r = await GameHub.gameOver({ score: 1234, meta: { level: 5 } });
  // r.score = { saved, best, isNewBest, rank }  — saved=false nếu là khách

  GameHub.unlockAchievement('first_blood');    // key khai báo trong gamehub.json
  GameHub.save({ level: 5, coins: 40 });       // JSON ≤ 64KB / người chơi / game
  const lb = await GameHub.leaderboard({ period: 'week', limit: 10 });

  GameHub.on('pause',  () => pauseGame());     // tab bị ẩn
  GameHub.on('resume', () => resumeGame());
  GameHub.on('mute',   e => setMuted(e.muted)); // nút tắt tiếng của portal
</script>
HàmMô tả
init()Gọi đầu tiên. Trả về thông tin người chơi.
ready()Báo đã tải xong.
gameStart() / gameOver({score?, meta?})Đánh dấu một lượt chơi; gameOver có thể gửi luôn điểm.
submitScore(score, meta?)Gửi điểm riêng lẻ. Tối đa 1 lần / 2 giây. meta ≤ 2KB.
unlockAchievement(key)Trả về { newlyUnlocked }. Gọi lặp lại vô hại.
save(data) / load()Lưu/đọc tiến trình trên tài khoản. Khách: không lưu.
leaderboard(opts)Top người chơi theo day | week | all.
requestReward(placement)Mời người chơi làm nhiệm vụ để nhận thưởng (mục 4). Tên cũ: showRewardedAd.
rewardStatus(placement)Kiểm tra trước có nhận được không (để ẩn/hiện nút), không mở giao diện.
on(event, fn)pause, resume, mute, task ({open, placement} — người chơi đang làm / đã xong nhiệm vụ nhận thưởng).

Mọi hàm trả về Promise. Khi mở game độc lập (không trong GameHub) SDK chạy chế độ mock: dữ liệu lưu trong localStorage, log ra console, GameHub.player.mock === true.

Giao thức (nếu muốn tự viết SDK)

Game nói chuyện với portal bằng window.parent.postMessage. Game → portal: {gh:1, id, type, payload} với type ∈ init, ready, gameStart, gameOver, submitScore, unlockAchievement, save, load, leaderboard, event. Portal trả lời {gh:1, replyTo:id, ok, data | error} và gửi sự kiện {gh:1, event:'pause'|'resume'|'mute'|'task', data}. Chỉ tin tin nhắn có event.source === window.parent.

4. Nhiệm vụ nhận thưởng (thay cho quảng cáo thưởng)

Thay vì xem quảng cáo, người chơi làm một nhiệm vụ do quản trị viên GameHub tạo — ví dụ xem live TikTok 30 giây, đọc một bài viết Facebook, xem video YouTube — rồi game trao thưởng. Game không cần biết nhiệm vụ là gì; game chỉ khai báo phần thưởng và gọi SDK.

// gamehub.json: "permissions": [..., "rewards"], "rewards": [ { "placement": "revive", "name": "Hồi sinh",
//   "reward": { "type": "revive", "amount": 1 }, "cooldownSec": 30, "dailyLimit": 10 } ]

// Có thể đọc cấu hình đã khai báo:
GameHub.rewards.revive   // { placement, name, reward: {type, amount}, cooldownSec, dailyLimit }

reviveButton.onclick = async () => {
  const r = await GameHub.requestReward('revive');   // portal tạm dừng game và hiện danh sách nhiệm vụ
  if (r.rewarded) revivePlayer(r.reward.amount);       // game tự trao thưởng
  else if (r.reason === 'cooldown') showToast(`Thử lại sau ${r.retryAfterSec} giây`);
};
Kết quảÝ nghĩa
{ rewarded: true, reward, placement, token, task }Người chơi đã làm xong. token là chữ ký của GameHub (dành cho game có server riêng muốn đối chiếu).
reason: 'closed'Người chơi đóng bảng nhiệm vụ.
reason: 'cooldown'Chưa hết cooldownSec kể từ lần nhận trước — kèm retryAfterSec.
reason: 'limit'Hết lượt hôm nay (theo dailyLimit của game hoặc giới hạn chung của hệ thống).
reason: 'no_tasks' | 'disabled' | 'login'Chưa có nhiệm vụ nào / quản trị viên tắt tính năng / cần đăng nhập.

Luồng ở phía người chơi: chọn nhiệm vụ → bấm Mở (link mở ở tab mới) → ở lại đủ thời gian (và nhập mã xác nhận nếu nhiệm vụ yêu cầu) → bấm Nhận thưởng. Máy chủ GameHub kiểm tra thời gian, mã, cooldown và giới hạn; game bị tạm dừng (sự kiện pause) và tắt tiếng trong lúc đó.

Bảo vệ nhân vật khi làm nhiệm vụ: portal gửi task với {open:true} khi mở khung nhiệm vụ và {open:false} khi đóng. Game nên cho nhân vật tàng hình / bất tử trong khoảng này (nhất là game online, vì đấu trường không dừng lại) và cho vài giây bảo vệ khi hiện lại. Với phòng multiplayer, máy chủ GameHub biết người chơi có đang làm nhiệm vụ thật hay không (services.taskActive) nên client không tự bật tàng hình để gian lận được. Khi chạy độc lập (mock), requestReward luôn trả rewarded: true để bạn thử nhanh.

5. Chơi nhiều người (multiplayer)

GameHub có máy chủ realtime (WebSocket). Game khai báo trong gamehub.json rồi dùng GameHub.multiplayer.join() — SDK tự xin "vé" qua portal và kết nối, bạn không cần viết server.

// gamehub.json
"permissions": [..., "multiplayer"],
"multiplayer": { "mode": "relay", "maxPlayers": 4, "minPlayers": 2, "privateRooms": true }
Chế độAi dùng đượcCách hoạt động
relayMọi game đăng lên (tối đa 16 người/phòng)Máy chủ chuyển tin giữa người chơi, giữ trạng thái phòng dạng key/value và chọn host (người vào đầu tiên; host rời thì chuyển cho người kế). Logic game chạy ở client — thường host quyết định kết quả.
authoritativeChỉ game hệ thống (tối đa 50)Máy chủ chạy logic game (va chạm, điểm, bot) và tự ghi điểm — không gian lận được. Ví dụ: Cubes 2048. Game đăng lên không thể chạy mã trên máy chủ.
const room = await GameHub.multiplayer.join();               // ghép phòng công khai
// await GameHub.multiplayer.join({ create: true })          // tạo phòng riêng -> room.code (6 ký tự) gửi cho bạn bè
// await GameHub.multiplayer.join({ code: 'K7QX2M' })        // vào phòng riêng bằng mã

room.me        // { id, name, avatar, guest }
room.players   // { [id]: {id, name, avatar, guest} }
room.host      // id của host; room.state: trạng thái chung

room.on('join',  p => addPlayer(p));
room.on('leave', p => removePlayer(p.id));
room.on('host',  id => iAmHost = id === room.me.id);
room.on('move',  (data, fromId) => moveRemote(fromId, data));   // tin nhắn tự đặt tên
room.on('state', (key, value) => render());
room.on('close', () => showDisconnected());

room.send('move', { x: 10, y: 4 });          // gửi cho mọi người khác
room.sendTo(playerId, 'hint', { ... });      // gửi riêng
room.setState('turn', room.me.id);           // ai cũng nhận sự kiện 'state'
const ms = await room.ping();                // độ trễ
room.leave();

Giới hạn: mỗi tin ≤ 16KB, khoảng 40 tin/giây/người (gửi vị trí khoảng 10–20 lần/giây là đủ), trạng thái phòng ≤ 64 khóa / 16KB. Phòng trống tự đóng sau 30 giây. Khi chạy độc lập (mock) hoặc ở chế độ xem thử, join() báo lỗi code: 'offline' — hãy có chế độ chơi đơn dự phòng. Lịch sử trận được lưu vào hồ sơ người chơi.

6. Môi trường chạy & ràng buộc kỹ thuật

  • Game chạy trong iframe sandbox (allow-scripts allow-pointer-lock, không có allow-same-origin): không truy cập được cookie, localStorage, IndexedDB hoặc DOM của portal. Dùng GameHub.save() để lưu dữ liệu.
  • CSP nghiêm ngặt: chỉ nạp tài nguyên từ chính gói game (và data:/blob:); mọi fetch/WebSocket/CDN/font ngoài đều bị chặn (trừ kết nối multiplayer tới chính máy chủ GameHub qua SDK). Hãy đóng gói thư viện (Three.js, Phaser…) vào zip.
  • Không có popup, form submit, hoặc điều hướng trang cha. Fullscreen do portal điều khiển.
  • Game nên co giãn theo kích thước khung (window.innerWidth/innerHeight) và hỗ trợ tạm dừng khi nhận pause.
  • Điểm gửi từ phía client nên được xem là không tuyệt đối đáng tin; hãy khai báo scoring.max hợp lý. Hệ thống giới hạn tần suất gửi điểm.

7. Tiêu chí duyệt

  • Đạt kiểm tra tự động (manifest hợp lệ, file được phép, entry tồn tại, không tải tài nguyên ngoài).
  • Game chạy được, không treo/lỗi trong vài phút đầu; có hướng dẫn chơi rõ ràng.
  • Phần thưởng nhiệm vụ hợp lý, không bắt người chơi làm nhiệm vụ mới chơi được phần chính của game.
  • Có gọi ready(); nếu có bảng điểm thì gửi điểm bằng SDK; thành tựu khai báo đều có thể đạt được.
  • Nội dung phù hợp mọi lứa tuổi: không bạo lực thái quá, không nội dung người lớn, không vi phạm bản quyền, không quảng cáo/ theo dõi người chơi.
  • Không cố thoát sandbox, đào tiền ảo, thu thập dữ liệu hoặc gọi ra ngoài.

8. Công cụ

# kiểm tra thư mục hoặc zip trước khi gửi
npm run validate -- ./my-game
npm run validate -- ./my-game.zip

# đóng gói
cd my-game && zip -r ../my-game.zip . -x ".*"

Mẫu để bắt đầu: thư mục sample-game/ trong mã nguồn GameHub (game "Click Rush" đầy đủ SDK, bảng điểm và thành tựu).

Icon có sẵn

GameHub dùng bộ icon Lucide (giấy phép ISC). Dùng các tên dưới đây cho icon của thành tựu. Trong game của bạn, có thể chép file icons.js (sinh bằng node tools/build-icons.js) vào gói và gọi ic('trophy') để lấy SVG, hoặc ic.draw(ctx, 'shield', x, y, cỡ, màu) để vẽ lên canvas.
